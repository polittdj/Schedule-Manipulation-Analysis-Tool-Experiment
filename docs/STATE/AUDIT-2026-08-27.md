### The fix (CONFIRMED-FIXED) — `timescale.js` load-path sanitizer + `labelDef` belt

Ranges coerce-then-clamp (`size` → [25,1000]; tier `count` → [1,999] floored); enums must be
members or the field keeps its default (`show` ∈ {1,2,3}, `fyStartMonth` ∈ integers 0–11, tier
`units`/`label`/`align`, nonworking `draw`/`pattern`, `color` pinned to the dialog's own
`#rrggbb(aa)` shape before it reaches CSS strings); healing is in-memory (idempotent per load;
storage heals on the next OK). `labelDef` gains the same months-fallback `tierBands` already had
for `UNITS`, so the B2 crash is dead even for a future unvalidated path. The load moved below the
UNITS/LABELS tables (it needs them to validate; nothing reads CFG before they exist).

Proof chain (QC-1):
- **Red first**: all 8 hardening tests in `tests/web/test_timescale_dialog_browser.py` observed
  to FAIL on the pre-fix tree, each on the defect it names (size 1 kept, 100000 kept, `"600000"`
  kept as a string, `"abc"` kept, `bogus` units kept, show 0 kept, bars pinned at the 2px floor,
  670,000px track).
- **Green**: 16/16 after the fix (≈37s — inside the browser-job budget).
- **Mutation battery, by name**: size clamp removed → the 6 size/matrix tests red;
  tier sanitize bypassed → hostile-tier test red on the units assert while the `labelDef` belt
  still prevented the crash; belt ALSO reverted → red on the crash channel with the exact
  original pageerror text (the test was restructured to force a tier REBUILD first — the crash
  lives in `tierBands`, and a load-time-only check can outrun the error collector);
  show/fy passthrough → its test red. Seed-vacuity is excluded by the pre-fix reds themselves
  (a vacuous seed cannot produce `assert 0 == 3` or `'600000' == 1000`).
- **End-to-end**: the matrix probe re-run on the fixed tree — A2/A4/B2 heal on all three pages
  (A2: tracks 4,750–10,560px, live controls, 0 errors); A1/A3 heal to size 25, where the
  measured geometry (track 120, bar 16–25px) is byte-class-identical to the DIALOG's own legal
  25% (measured separately: track 120, bar 24, factor 0.25) — those residual probe rows are the
  smallest-legal zoom, **REFUTED as defects**.
